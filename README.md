# CyberGuard Security Operations Platform

A modern cybersecurity dashboard themed for a real Security Operations Center (SOC) with executive monitoring, threat detection, asset health, and incident tracking.

## Features

- Executive threat overview dashboard
- Live threat feed and attack trend visualization
- Security score and risk posture
- Asset health and vulnerability matrix
- Incident timeline and case queue
- Responsive dark cyber design

## Run locally

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 3000
```

Then open the app in your browser at:

http://localhost:3000

## Production note

This project is a production-style frontend dashboard. For a fully real cybersecurity system, it can be connected to a backend with authentication, SIEM ingestion, asset inventory, real incident APIs, and alert rules.
